## 📌 Overview

Large language models are increasingly used in dialogue systems such as assistants, tutors, customer-service applications, and social chatbots. Although their responses often appear natural, they may differ from human conversations in lexical, syntactic, stylistic, and interactional patterns.

This project investigates **which linguistic properties distinguish human-human dialogue from LLM-generated dialogue**, whether these properties can support detection, and whether the observed differences remain robust after superficial text transformations.

> **Core principle:** The objective is not simply to achieve the highest classification score. We aim to understand *what* the models detect, *why* the differences occur, and whether they reflect robust conversational behavior rather than dataset-specific artifacts.

## 🎯 Research Questions

We will investigate:

- What basic linguistic and conversational properties differ between human and LLM-generated dialogues?
- Are there systematic lexical, syntactic, stylistic, or interactional differences?
- Do humans and LLMs differ in how they adapt their language to their conversational partner?
- Can linguistic properties be used to distinguish human from LLM-generated dialogue?
- Do interpretable linguistic features improve on a text-only baseline?
- Do observed differences remain after meaning-preserving text transformations?
- Do patterns learned from one LLM generalize to dialogue generated by another LLM?

## 📚 Datasets

| Dataset | Description |
|---|---|
| [EmpatheticDialogues](https://github.com/facebookresearch/EmpatheticDialogues) | Conversations between human participants |
| [2GPTEmpathicDialogues](https://github.com/morganlee123/2GPTEmpathicDialogues) | Conversations generated by two independent ChatGPT instances under scenarios corresponding to EmpatheticDialogues |

Before conducting experiments, we will perform an exploratory analysis covering:

- Number of dialogues
- Distribution of turns per dialogue
- Distribution of words per turn
- Sentence-length statistics
- Representative examples
- Potential dataset artifacts, formatting conventions, and class-specific signals

## 🔬 Methodology

### 1. Exploratory Data Analysis

We will inspect both corpora to identify basic structural and stylistic differences that could make classification artificially easy.

Examples of potential confounding factors:

- Systematically longer LLM responses
- More regular conversation lengths
- Distinct punctuation or capitalization conventions
- Expressions that appear predominantly in one corpus
- Formatting or preprocessing differences

### 2. Linguistic Feature Analysis

We will select a focused set of features from at least **three linguistic levels**.

| Level | Candidate features |
|---|---|
| Lexical | Turn length, sentence length, lexical diversity, repetition, contractions, vocabulary overlap |
| Syntactic | Part-of-speech distributions, dependency-tree depth, dependency distance, clause density |
| Stylistic / Pragmatic | Questions, hedging, intensifiers, politeness, formality, punctuation, acknowledgements, sentiment |

For each selected feature, we will:

1. Define how the feature is calculated.
2. Calculate it for each dialogue.
3. Compare its distribution across the two corpora.
4. Quantify the magnitude of the observed difference.
5. Interpret what the difference may reveal about conversational behavior.

### 3. Conversational Alignment

Human conversational partners often adapt their language to one another. This phenomenon is commonly called **linguistic accommodation** or **alignment**.

We will implement at least one alignment measure, such as:

- Language Style Matching (LSM)
- Lexical overlap between consecutive turns
- Semantic similarity between consecutive turns
- Similarity in utterance length
- Syntactic alignment
- Emotional alignment

We will compare alignment distributions and examine whether alignment:

- Differs between human-human and LLM-generated conversations
- Changes as the conversation progresses
- Is consistent throughout a dialogue
- Produces similar conclusions across stylistic and semantic measures

### 4. LLM-Generated Dialogue Detection

We will build and compare three classifier configurations:

| Model | Input |
|---|---|
| Text-only baseline | Text representation |
| Linguistic-feature model | Interpretable linguistic and conversational features |
| Combined model | Text representation + linguistic features |

Evaluation metrics:

- Accuracy
- Precision
- Recall
- Macro-F1

Beyond performance, we will analyze which features contribute most strongly and whether linguistic features improve interpretability and robustness.

### 5. Robustness Analysis

To determine whether the classifier relies on superficial properties, we will create at least one meaning-preserving modified version of the evaluation data.

Potential transformations include:

- Punctuation and capitalization normalization
- Spelling correction
- Contraction normalization
- Utterance-length control
- Language-model paraphrasing

**Important:** Any transformation must be applied using the same procedure to both human and LLM-generated dialogue. Otherwise, the transformation process itself may introduce a class-specific signal.

We will compare:

- Classification performance before and after transformation
- Linguistic differences before and after transformation
- Features that remain stable
- Features that disappear
- What performance changes imply about the original classifier

### 6. Error Analysis & Hypotheses

We will inspect conversations that:

- Were incorrectly classified
- Changed classification after transformation
- Received different predictions from text-based and linguistic-feature models
- Contain recurring phenomena such as unusually long responses, follow-up questions, politeness, or formality

Based on these observations, we will formulate **2–3 hypotheses** explaining why human and LLM conversations can or cannot be distinguished.

## 📊 Evaluation Principles

We will prioritize:

- **Interpretability:** Explain which linguistic properties drive observed differences.
- **Robustness:** Test whether findings survive meaning-preserving transformations.
- **Fair comparison:** Apply preprocessing and transformations consistently across classes.
- **Reproducibility:** Keep data preparation, feature extraction, and experiments documented.
- **Scientific caution:** Treat unexpected or negative results as valuable findings.
- **Generalization:** Consider whether patterns extend beyond a single dataset or model.
